## UI/UX Updates (June 2024)

### Latest Design Overhaul
- **Inspiration:**
  - Inspired by dark, futuristic, techy landing pages and the Jules site (https://jules.google/).
  - Uses the Aurora Dreams palette: #1B1641, #3C249C, #832AD0, #47FFBF, #35DECE, #2D9ABB.
  - Features pixel/ASCII art, retro fonts, and playful, glowing neon effects.

### Changes Made
- **Dark Mode:**
  - Default dark background with gradients and floating neon shapes.
- **Aurora Dreams Palette:**
  - All colors updated to match the provided palette for a cohesive, vibrant look.
- **Pixel/ASCII Art:**
  - Logo and critter in header use ASCII art and pixel font.
  - Floating pixel/ASCII art elements for fun and retro vibes.
- **Retro/Techy Styling:**
  - Glassmorphism panels, glowing borders, and pixel font throughout.
  - Subtle animations and playful layout.

### Reasoning
- The new design is fun, engaging, and visually unique, matching the user's request for a retro-futuristic, techy, and playful style.
- The Aurora Dreams palette provides a modern, harmonious, and energetic color base.
- Pixel/ASCII art and retro fonts add personality and nostalgia, making the app stand out.

# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
